# Claim Boundaries

This repository intentionally uses careful wording.

## Safe claims

- local-runnable
- production-style reference framework
- AWS-patterned
- EMR-compatible
- SageMaker-compatible
- public/proxy fraud benchmark style
- synthetic ISO 20022-inspired payment workflows
- offline feature-store artifacts
- point-in-time feature engineering
- Risk/Compliance-ready documentation artifacts

## Do not claim unless actually performed

- used proprietary bank data
- used JPMorgan Chase data
- deployed to production
- processed real customer payment data
- operated a real fraud-detection system
- ran on AWS EMR or SageMaker managed infrastructure
- obtained formal Risk/Compliance approval

## Data statement

The demo uses generated public-style fraud records, generated CFPB-style complaint narratives, and synthetic ISO 20022 sample files when available locally. It is designed for portfolio evidence and interview discussion, not for production fraud decisions.
